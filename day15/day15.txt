Data ingestion :
SNOWPIPE & STREAMING:
1. Batch ingestion: retail company exports its sales data daily night
sales app -> sales.csv -> stage -> copy inyo -> table

2. snowpipe -> rather giving copy into everytime,,snowpipe can automatically uploaded the data

snowpipe designed for continuous file - based ingestion

3. snowpipe streaming -> retail applicated generates 1000s of invidual sales events, instead of waiting for your CSV file to be genereated . the app can send rows directly into snowflake table using snowpipe streaming

snowpipe streaming does not required the traditional staged file workflow

bulk loading -> COPY into
if files are continuosly loaded then use snowpipe
    if row level ingestion required -> snowpipe streaming
